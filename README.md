# Hood Boss Technician Team Lead Path

Technician-only Team Lead prep site.

Live URL target:

https://antmanthepro.github.io/hood-boss-tech-lead-path/

## Purpose

This repository intentionally separates technician-facing prep from manager-facing candidate scoring, audit trails, and employment-decision materials.

## What is included

- watchable Team Lead briefing
- interview practice mode
- technician self-check
- work-order workflow trainer
- scenario trainer
- local-only notes export
- responsive mobile/desktop layout
- single-file static deployment

## What is excluded

- manager scoring
- candidate ranking
- audit logs
- HR/TWC defense material
- employee decision recommendations

## Deploy on GitHub Pages

1. Create a public repo named `hood-boss-tech-lead-path`.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repo root.
3. Go to Settings -> Pages.
4. Source: Deploy from branch.
5. Branch: main / root.
6. Save.

The site will publish at:

https://antmanthepro.github.io/hood-boss-tech-lead-path/
